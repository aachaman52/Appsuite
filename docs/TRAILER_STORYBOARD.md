## Detailed Scene Specifications

### Scene 1 — The Problem | 0–10 sec
- **Atmosphere**: Minimal dark developer workspace illuminated by ambient monitor glow.
- **Visuals**:
  - Overlapping floating dark glass application windows: VS Code (`main.py`), Godot Engine 4 (`MainScene.tscn`), Blender 4.2 (`village_building.fbx`), Terminal (`cmake build`), Asset Folder (`/textures/stone/`).
  - Red/orange dashed vector lines tracking fragmented steps: `Code → Assets → AI → Engine → Build → Testing`.
  - Typewriter overlay text appearing at 0:02s: *"Game development shouldn't feel like managing 20 different systems."*
- **Transition**: Dissolve into dark vignette revealing the Aachman Studios flame logo mark.

### Scene 2 — The Vision | 10–20 sec
- **Atmosphere**: Dynamic 3D network node space with deep dark background (`#07090E`).
- **Visuals**:
  - Node graph connecting 7 primary nodes:
    `Developer` ➔ `AppSuite` ➔ `Jarvis AI Engine` ➔ `Specialized Agents` / `GameDevAI Suite` ➔ `PyFlare OS` ➔ `Build / Test / Deploy`.
  - Particles and glowing cyan data packets streaming along vector links representing code, 3D meshes, AI tokens, and build artifacts.

### Scene 3 — AppSuite + Jarvis | 20–35 sec
- **Atmosphere**: Clean desktop development interface.
- **Visuals**:
  - AppSuite IDE top bar with prompt input field.
  - Typewriter prompt: `"Create a playable medieval village scene."`
  - Jarvis technical orchestration panel showing DAG task runner:
    `Plan` ➔ `Find/Create Assets` ➔ `Process Assets` ➔ `Blender` ➔ `Godot` ➔ `Test` ➔ `Build`.
  - Parallel telemetry bars displaying Asset Worker (PolyHaven API), Mesh Worker (Blender Python API), GDScript Worker (GameDevAI), and Engine Validator (Godot 4.3 headless).
  - Explicitly non-humanoid: portrayed as pure software orchestration intelligence.

### Scene 4 — Intelligent Model Routing | 35–47 sec
- **Atmosphere**: High-tech telemetry telemetry matrix.
- **Visuals**:
  - Model evaluation cards for `Phi-3-Mini` (Selected, 0.04 TFLOPS), `Llama-3-8B` (0.18 TFLOPS), `Codegen-Small` (0.02 TFLOPS), and Cloud LLM Fallback (Suppressed).
  - Deterministic router pipeline: `User Intent` ➔ `Task Classification` ➔ `Local Model Evaluation` ➔ `Deterministic Router` ➔ `Best Model`.
  - Telemetry gauge showing CPU & GPU resource usage on a laptop hardware setup.
  - Subtitle: *"Use the right intelligence for the right task."*

### Scene 5 — PyFlare OS | 47–62 sec
- **Atmosphere**: Authentic Linux system boot sequence.
- **Visuals**:
  - 47–50s: GRUB 2 bootloader menu (*PyFlare OS - Codename Ember - Ubuntu 24.04 LTS*).
  - 50–53s: Plymouth boot splash featuring animated ember flame.
  - 53–56s: GDM3 Login screen.
  - 56–62s: GNOME Dark Desktop with `pyflare-cli system-status` terminal window streaming diagnostic logs.
  - System architecture layer overlay: `Linux Kernel` ➔ `System Services` ➔ `PyFlare Engine` ➔ `Jarvis AI` ➔ `Developer Applications`.

### Scene 6 — The Developer Workflow | 62–75 sec
- **Atmosphere**: Automated game engine execution.
- **Visuals**:
  - Godot Engine 4.3 viewport opening with wireframe 3D grid and medieval house mesh instantiations.
  - Right panel running automated unit tests (`pytest tests/test_scene.py`) with green checkmarks (`[PASSED ✓]`).
  - Final compilation completing with glowing green banner: `BUILD SUCCESSFUL`.

### Scene 7 — The Ecosystem | 75–85 sec
- **Atmosphere**: Architectural tree perspective.
- **Visuals**:
  - Zoom out into ecosystem hierarchy:
    ```
    Aachman Studios
    ├── AppSuite
    ├── Jarvis AI
    ├── GameDevAI
    ├── PyFlare OS
    ├── Developer Tools
    └── Future Ecosystem
    ```
  - Subtitle: An actively engineered ecosystem with a clear long-term vision.

### Final Scene — Brand Resolution | 85–90 sec
- **Atmosphere**: Ultra-clean modern studio workspace.
- **Visuals**:
  - Camera settling on sleek workstation.
  - Official vector rendering of the **Aachman Studios Logo** (`#5B5FFF` left petal, `#8A5CF5` right petal, `#00D4FF` center flame).
  - Typography: **AACHMAN STUDIOS**
  - Subtitle: *"Building tools for the people who build the future."*
  - Smooth fade to black.
