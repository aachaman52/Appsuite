# AppSuite Ecosystem — Plugin System

**Version:** 1.0.0 | **Status:** Production | **Author:** Aachman Studios | **Last Updated:** 2026-08-04

---

## Overview

AppSuite Jarvis includes an extensible plugin system allowing third-party integrations, custom agents, and additional asset sources to be added without modifying core code.

There are two plugin systems:
1. **Core Plugin System** (`appsuite/core/plugin_manager.py`) — used by the Pipeline and Workers
2. **Phase 11 Plugin System** (`appsuite/plugins/`) — event-driven, discovered at startup

---

## BasePlugin Interface

All plugins inherit from `BasePlugin` and implement lifecycle hooks:

```python
from appsuite.plugins import BasePlugin, PluginContext

class CustomPlugin(BasePlugin):
    name = "MyPlugin"
    version = "1.0.0"

    async def on_start(self, context: PluginContext):
        """Called when the plugin is loaded."""
        pass

    async def on_post_code_generation(self, context: PluginContext):
        """Called after code is generated by CodeWorker."""
        filepath = context.get("latest_file")
        # custom linting, analysis, etc.

    async def on_job_complete(self, context: PluginContext):
        """Called when a job finishes successfully."""
        pass

    async def on_job_failed(self, context: PluginContext):
        """Called when a job fails."""
        pass
```

---

## Available Hooks

| Hook | When Called |
|---|---|
| `on_start` | Plugin loaded at system startup |
| `on_pre_execution` | Before any worker runs |
| `on_post_code_generation` | After `CodeWorker` generates code |
| `on_post_blender` | After `BlenderWorker` completes |
| `on_post_godot` | After `GodotWorker` completes |
| `on_validation_complete` | After `ValidationWorker` runs |
| `on_job_complete` | Job succeeded |
| `on_job_failed` | Job failed after all retries |
| `on_shutdown` | System shutting down |

## Plugin Discovery

On startup, `PluginManager` scans the `plugins/` directory for Python files:

```python
class PluginManager:
    def discover_and_load(self):
        for py_file in self.plugins_dir.glob("*.py"):
            spec = importlib.util.spec_from_file_location(...)
            module = importlib.util.module_from_spec(spec)
            spec.loader.exec_module(module)
            # Find BasePlugin subclasses and instantiate
```

## Plugin Context

`PluginContext` provides access to:

```python
context.get("latest_file")           # Most recently written file path
context.get("job_id")                 # Current job ID
context.get("prompt")                 # Original user prompt
context.trigger_repair(errors)        # Trigger self-healing loop
context.db                            # Database access
context.registry                      # Asset registry
```

## Configuration

```yaml
# config/default_config.yaml
plugins:
  enabled: true
  directory: "plugins"
```

Disable all plugins: set `enabled: false`.
Point to a different directory: change `directory`.
